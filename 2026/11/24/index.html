📚 行业学习 广告 · 商业 · 营销
今日主题 · B2A 经济
当购物者不是人：a16z 一万次实测背后的"Agent 优化"新战场
从 SEO、GEO 到 BAO——被 AI Agent 替代的消费者，正在改写营销的基本假设

a16z 做了一件营销行业迟早都要面对的事：让 AI Agent 真的去购物。1,270 条提示词、11,307 次完整购买流程、覆盖 Grok Bot、Muse、Instinct、Dots 等主流购物智能体，再比对 YipitData 的真实消费数据——结论指向一个新词：B2A（Business to Agent）经济。企业要赢得的下一个顾客，可能根本没有眼睛。

这个转变的深刻之处在于：过去二十年营销的所有技巧，都建立在对"人"的理解之上——注意力稀缺、情感共鸣、视觉冲击、从众心理。但 Agent 不看广告，不刷信息流，不为情怀买单。它读取结构化数据、比价、验证评价、执行预算约束。品牌在 Agent 眼中的形象，取决于商品数据的质量、服务的可验证性、履约的确定性——这些恰恰是传统营销最不看重的"基本功"。

a16z 总结的五条方法，本质上是一份"机器友好度"清单：让 Agent 能读懂你的商品（结构化、无歧义）、能信任你的承诺（评价可验证）、能顺利完成交易（支付与履约对机器无摩擦）。有趣的是，这些原则与小红书"种草效果化"的方向暗合——当种草链路被 AI 拆解和度量，"内容种草"的价值终将被翻译成 Agent 能理解的语言。

对营销人而言，这不是终点而是分层：to C 的情感连接依然存在，但 to A 的机器沟通成为新增必修课。就像十五年前每个品牌都要学 SEO，五年前都要学直播，接下来两年，"你的品牌对 Agent 说什么、怎么说"将写进每一份年度营销方案。先行者已经在做了——问题只是，你的组织里谁负责这件事。

NeurIPS 神经信息处理系统大会
Conference on Neural Information Processing Systems · 始于1987年，2026年恰逢第40届
【过去】从几百人的"神经网络互助小组"到 AI 世界的奥林匹克

1987年，丹佛。深度学习还是学界眼里的"冷门偏方"，一群相信神经网络的人聚在一起，办了第一届 NeurIPS（当时叫 NIPS）——参会者不过数百人，像一个抱团取暖的互助小组。谁能想到，这个小组日后定义了整个智能时代。

2012年，AlexNet 在 ImageNet 上横空出世，深度学习纪元开启，NeurIPS 的命运随之改写：论文投稿量从几千篇膨胀到两万多篇，录用率长期压在25%左右，中稿成为研究者简历上最硬的通货。2018年，组织方正式更名为 NeurIPS——摆脱旧缩写，也宣告它已是覆盖机器学习全领域的中枢。

它的历年记忆点本身就是一部 AI 通史：2012年的深度学习黎明、2017年《Attention Is All You Need》的前夜气氛、Transformer 与大模型时代的军备竞赛。多少改变世界的想法，最早是在这里的海报展板前，被三五个研究者围着讨论出来的。

今天的 NeurIPS 已不只是学术会议，而是全球 AI 人才的年度定价场：顶会论文是科技巨头与实验室争夺人才的硬指标，会议期间的招聘酒会与公司展位密度堪比人才市场。OpenAI、DeepMind、Anthropic、Meta、Google 的核心研究者几乎全员到场——一次 NeurIPS，等于把全球最强的 AI 大脑装进同一个时区。

运作模式也独具一格：投稿由社区志愿者大规模评审，论文以海报（Poster）、口头报告（Oral）、聚焦报告（Spotlight）分级展示；工作坊（Workshops）与竞赛（Competitions）覆盖从气候建模到量子计算的边缘方向。2026年第40届首次采用悉尼、亚特兰大、巴黎三城联动的形式，让不同时区的研究者就近参与——会议本身的组织形式，也在回应"AI 是全球协作产物"这个命题。

【未来】四十岁的 NeurIPS 与对小红书平台大事件业务的启发

本届看点：推理模型与 Agent 成为绝对主线，形式化数学验证（本周 Lean 社区刚确认黎曼猜想证明）预计将带动"AI 做数学"方向的热度；同时，多城联动模式如果跑通，可能成为顶级会议应对规模膨胀与碳足迹的新范式。四十周年之际，回头看1987年那几百人的小组——技术的信仰者，最终等来了技术的时代。

对小红书平台大事件业务的启发：NeurIPS 最重要的产品不是论文，而是"在场感"——一张海报展板前的争论、一场酒会上的偶遇，产出的是信任与协作网络，这正是线上会议无法替代的稀缺品。小红书的大事件设计同样如此：活动的核心资产不是曝光量，而是让关键人群（创作者、品牌、用户）在同一物理或情感场域中"相遇"。另外，NeurIPS 用近四十年把一个学术聚会经营成行业定价标准——大事件IP也应该追求成为某个赛道的"年度必经仪式"，而不是一场孤立的爆款活动。

记忆点：1987年，一群"研究冷门"的人开了一场几百人的小会；2026年，这场小会的第40届同时点亮悉尼、亚特兰大、巴黎三个时区。所有改变世界的浪潮，最初都只是少数人的坚持。
